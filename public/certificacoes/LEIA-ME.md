# Badges das certificações

Coloque aqui o badge oficial de cada certificação, baixado do seu perfil no Credly
(abra o badge > Share > Download), com o nome igual ao `id` em `src/certificacoes.ts`:

- `secplus.png`: CompTIA Security+
- `az900.png`: Microsoft Azure Fundamentals

Se o badge tiver fundo branco (sem transparência), marque `badgeFundo` na certificação, para não aparecer um
quadrado branco no tema escuro: `'disco'` para badges redondos, `'cartao'` (cantos arredondados) para escudos. Um quadrado de 320×320 px basta.

Enquanto o arquivo não existe, o app mostra um selo neutro com o código da prova.
